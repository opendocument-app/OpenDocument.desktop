## What this is

The desktop edition of OpenDocument Reader, for Windows, macOS and Linux. It is
a Tauri 2 app. The Rust side owns the windows, the menus and the file access.
The frontend owns the user interface, and it runs the core.

The renderer is [OpenDocument.core](https://github.com/opendocument-app/OpenDocument.core).
Unsupported formats and rendering bugs belong there, not here.

## Rules

- The app compiles no C++. It uses the WebAssembly build of the core from npm,
  `@opendocument/odr-core`. Change the version in `package.json` only.
- `public/odr/` is generated by `scripts/sync-odr.mjs`. Do not commit it.
- The document stays on the computer. The app makes no network request.
- Keep the identifier `app.opendocument.desktop`. A new identifier is a new app
  for the stores and for the settings on disk.
