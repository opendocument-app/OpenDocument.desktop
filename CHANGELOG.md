# Changelog

User-facing changes of the desktop app, including what the app takes from the
OpenDocument core.

Add an entry under `Unreleased` in the pull request that makes the change.
Before a release, a pull request changes that heading to the version.

## Unreleased

- The first version of OpenDocument Reader for Windows, macOS and Linux. It opens
  OpenDocument, Word, Excel, PowerPoint, PDF, Pages, Numbers, Keynote and more,
  also with a password.
- Edit and save text documents, spreadsheets and presentations, and mark up PDFs.
- Search, zoom, print, a tab for each sheet, recent documents, and new empty
  documents.
